# تطبيق ذكاء اصطناعي محلي (شات بوت + مستندات الشركة)

تطبيق شات بوت ذكاء اصطناعي يتم تركيبه على جهاز الكمبيوتر الشخصي (بدون كارت شاشة قوي)، مع دعم:
- تعدد المستخدمين (كل واحد بحسابه الخاص).
- الرد بناءً على مستندات/بيانات الشركة (RAG) عن طريق رفع الملفات في النظام.
- الوصول من أجهزة أخرى (موبايل/لابتوب) على نفس الشبكة أو من بعيد.

المكونات:
- **Ollama**: يشغّل موديل ذكاء اصطناعي صغير محليًا على المعالج (CPU) بدون الحاجة لكارت شاشة.
- **Open WebUI**: واجهة شات على المتصفح، فيها تسجيل دخول لكل مستخدم، ودعم مباشر لرفع المستندات والرد بناءً عليها (RAG) بدون أي إضافات.

## 1) المتطلبات
- تثبيت [Docker Desktop](https://www.docker.com/products/docker-desktop/) على ويندوز/ماك، أو Docker Engine على لينكس.
- 8 جيجا رام كحد أدنى (يفضل 16 جيجا لأداء أفضل).
- مساحة فاضية على الهارد ~10 جيجا للموديلات.

## 2) التشغيل لأول مرة
افتح Terminal/PowerShell في هذا المجلد (`local_ai_assistant`) ونفّذ:

```bash
docker compose up -d
```

ده هيشغّل الخدمتين في الخلفية. أول مرة هيحمّل الصور (Images) وده ممكن ياخد وقت حسب سرعة النت.

## 3) تحميل موديل ذكاء اصطناعي
بعد ما الخدمات تشتغل، حمّل موديل صغير مناسب للمعالج (بدون كارت شاشة):

```bash
docker exec -it ollama ollama pull qwen2.5:3b
```

موديلات مقترحة أخرى خفيفة على المعالج: `llama3.2:3b`، `phi3.5`. تقدر تجرب أكتر من موديل وتختار الأنسب من ناحية السرعة والدقة.

## 4) أول دخول وإنشاء حسابات المستخدمين
1. افتح المتصفح على: `http://localhost:3000`
2. أول حساب تسجّله بيصبح **Admin** تلقائيًا.
3. من `Admin Panel > Users` تقدر تضيف حساب لكل موظف/مستخدم، وتحدد صلاحياته.

## 5) تفعيل الرد من مستندات الشركة (RAG)
1. من القائمة اليمين: `Workspace > Knowledge`.
2. اعمل مجموعة جديدة (Knowledge Base) وارفع فيها ملفات الشركة (PDF, Word, TXT, Excel...).
3. في الشات، اكتب `#` واسم المجموعة، أو فعّلها كمصدر معرفة لموديل مخصص من `Workspace > Models`، وبعد كل سؤال هيرد الموديل بالاعتماد على محتوى الملفات دي.

## 6) الوصول من أجهزة تانية
### أ) نفس الشبكة (بيت/مكتب) — أسهل طريقة
1. اعرف الـ IP المحلي لجهازك:
   - ويندوز: `ipconfig` وشوف `IPv4 Address`
   - ماك/لينكس: `ifconfig` أو `ip a`
2. أي جهاز على نفس الواي فاي يقدر يفتح: `http://<الـ-IP-بتاع-جهازك>:3000`

### ب) الوصول من بره الشبكة — الطريقة الموصى بها: Tailscale
أأمن وأسهل حل بدون فتح بورتات على الراوتر، والاتصال مشفّر بين الأجهزة فقط:
1. سجّل حساب مجاني على [tailscale.com](https://tailscale.com) وثبّت البرنامج على جهاز الكمبيوتر (السيرفر) وعلى أجهزة باقي المستخدمين (موبايل/لابتوب).
2. سجّل دخول بنفس الحساب (أو ادعُ باقي المستخدمين كأعضاء في نفس الـ Tailnet).
3. كل جهاز بيبقى له IP خاص بشبكة Tailscale، والوصول يكون: `http://<Tailscale-IP-بتاع-جهاز-السيرفر>:3000`.

### ج) بديل: رابط عام بدون فتح بورتات — Cloudflare Tunnel
لو عايز رابط ثابت يفتح من أي مكان بدون تثبيت برنامج على أجهزة المستخدمين، استخدم Cloudflare Tunnel (يحتاج دومين مجاني/موجود عندك) مع تفعيل Cloudflare Access كطبقة تسجيل دخول إضافية قبل الوصول للتطبيق.

**تحذير مهم:** لا تفتح بورت 3000 مباشرة على الراوتر (Port Forwarding) للإنترنت العام بدون HTTPS وطبقة حماية إضافية — ده بيعرّض الجهاز والبيانات للخطر.

## 7) نصائح صيانة
- خد نسخة احتياطية (Backup) بشكل دوري لمجلدي الـ volumes (`ollama_data`, `open_webui_data`) اللي فيهم الموديلات والمستندات والمستخدمين.
- لتحديث البرنامج: `docker compose pull && docker compose up -d`
- لإيقاف الخدمات: `docker compose down` (البيانات تفضل محفوظة، مش بتتمسح).
