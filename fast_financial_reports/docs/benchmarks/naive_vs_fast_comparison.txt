=== Naive (search() + Python loop) vs Fast Financial Reports: real measurements ===
=== Same machine, same warm PostgreSQL cache, same filters, run 3x for consistency ===
===
=== Standard Odoo Trial Balance/General Ledger/Partner Ledger (account_reports) is an
=== Enterprise-only module and was not available in this Community-only sandbox, so a
=== direct comparison against it could not be produced (see README "Known limitations").
=== This benchmark instead compares against the exact anti-pattern the task explicitly
=== forbids - search() followed by a Python loop over account.move.line - which is what
=== an unoptimized/hand-rolled report (or a naive reimplementation of a standard report)
=== would do. This is a fair, real, and arguably more relevant comparison than a
=== synthetic one, since it isolates exactly the architectural choice this module makes.
